3. Create `prisma/seed.ts`:
```typescript
import { PrismaClient } from '@prisma/client';
const prisma = new PrismaClient();

async function main() {
  const existing = await prisma.pipeline.findFirst({ where: { name: 'Qualificacao' } });
  if (existing) { console.log('Default pipeline already exists'); return; }

  await prisma.pipeline.create({
    data: {
      name: 'Qualificacao',
      stages: {
        create: [
          { name: 'Novo', order: 0 },
          { name: 'Em Qualificacao', order: 1 },
          { name: 'Qualificado', order: 2 },
          { name: 'Desqualificado', order: 3 },
        ],
      },
    },
  });
  console.log('Default pipeline seeded');
}

main().catch(console.error).finally(() => prisma.$disconnect());
```

4. Add to package.json:
```json
"prisma": { "seed": "npx tsx prisma/seed.ts" }
```

2. Create `src/crm/pipeline.service.ts`:
- `getDefaultPipeline()`: Returns the first pipeline with its stages included. Throws if none exists ("Run prisma db seed first").
- `getStageByName(pipelineId: string, name: string)`: Finds a stage by name within a pipeline. Returns null if not found.

3. Create `src/crm/lead.service.ts`:
- `upsertLead(data: { phone: string; name?: string; vehicleUrl?: string })`: Uses Prisma `upsert` with `where: { phone_pipelineId: { phone, pipelineId } }`. On create, sets stageId to the "Novo" stage. Returns the lead with stage included.
- `updateLead(leadId: string, data: { name?, city?, creditStatus?, paymentMethod?, vehicleUrl? })`: Prisma update, returns updated lead.
- `moveToStage(leadId: string, stageId: string)`: Updates lead's stageId. Returns updated lead with stage.
- `addNote(leadId: string, content: string, type: 'ai' | 'human')`: Creates a LeadNote linked to the lead. Returns the note.

All functions use the shared Prisma client from `src/db/prisma.ts` (check if it exists; if not, create a simple lazy-init Prisma client file).

4. Create `src/conversation/conversation.service.ts`:
- `loadOrCreateConversation(phoneNumber: string, limit = 30)`:
  - Find lead by phone (any pipeline). If no lead, return `{ id: newConversationId, recentMessages: [], lead: null }`.
  - If lead exists, find or create Conversation for that lead. Load last `limit` messages ordered by createdAt asc. Parse each message.content as ChatCompletionMessageParam. Return `{ id, recentMessages, lead }`.
- `appendMessages(conversationId: string, messages: ChatCompletionMessageParam[])`:
  - Create Message records with `role` and `content: JSON.stringify(msg)` for each message.

Import types from `openai` package for ChatCompletionMessageParam.
