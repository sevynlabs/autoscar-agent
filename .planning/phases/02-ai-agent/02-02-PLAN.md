2. Create `src/agent/agent.tools.ts`:
- Export `AGENT_TOOLS: ChatCompletionTool[]` with 7 tool definitions:
  - `scrape_vehicle`: params `{ url: string }`. Description: "Busca dados e fotos do veiculo no autoscar.com.br"
  - `send_photos`: params `{ photos: string[] }`. Description: "Envia fotos do veiculo para o lead via WhatsApp" (actual sending done here; photos array from scraper result)
  - `create_lead`: params `{ name?: string, phone?: string, vehicle_url?: string }`. Description: "Cria ou atualiza card do lead no CRM"
  - `update_lead`: params `{ name?, city?, credit_status?, payment_method? }`. Description: "Atualiza dados do lead no CRM"
  - `move_lead_stage`: params `{ stage_name: string }`. Description: "Move o card do lead para outra etapa do pipeline". Accept stage_name (not stageId) — resolve internally via getStageByName.
  - `add_note`: params `{ content: string }`. Description: "Adiciona nota ao card do lead"
  - `notify_sellers_group`: params `{ summary: string }`. Description: "Envia resumo do lead qualificado para grupo de vendedores"

- Create Zod schemas for each tool's arguments: ScrapeVehicleArgs, SendPhotosArgs, CreateLeadArgs, UpdateLeadArgs, MoveStageArgs, AddNoteArgs, NotifyArgs.

- Export `executeToolCall(toolCall, ctx: AgentContext)`:
  - Parse args with JSON.parse, then validate with corresponding Zod schema.
  - `scrape_vehicle`: Call getVehicleData(url). Return `{ model, year, km, price, photoCount, photos }` (include photos array for send_photos to use).
  - `send_photos`: Send photos sequentially via evolutionClient.sendMedia (from Plan 03). For now, call `evolutionClient.sendMedia(ctx.instance, ctx.phoneNumber, photo, caption)` for each photo with 2.5s delay. If sendMedia doesn't exist yet, log a warning and skip — Plan 03 will add it.
  - `create_lead`: Call upsertLead({ phone: ctx.phoneNumber, name: args.name, vehicleUrl: args.vehicle_url }).
  - `update_lead`: Guard with `if (!ctx.lead) throw new Error('No lead in context')`. Call updateLead(ctx.lead.id, mapped args — map snake_case to camelCase).
  - `move_lead_stage`: Resolve stage via getStageByName(pipelineId, args.stage_name). If stage not found, return error object. Call moveToStage(ctx.lead.id, stage.id).
  - `add_note`: Call addNote(ctx.lead.id, args.content, 'ai').
  - `notify_sellers_group`: Call evolutionClient.sendText(ctx.instance, process.env.SELLERS_GROUP_JID!, args.summary). If SELLERS_GROUP_JID not set, log warning and return { skipped: true, reason: 'SELLERS_GROUP_JID not configured' }.
  - Default case: throw Error("Unknown tool").

3. Create `src/agent/agent.service.ts`:
- Lazy-init OpenAI client: `const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY })` — only instantiate on first call, not at import time (per Phase 1 pattern).
- Export `runAgentTurn(ctx: AgentContext): Promise<string>`:
  - Build messages array: system prompt + ctx.history + { role: 'user', content: ctx.userMessage }
  - Enter while loop with MAX_ITERATIONS = 10 counter.
  - Call `openai.chat.completions.create({ model: 'gpt-4o', messages, tools: AGENT_TOOLS, tool_choice: 'auto' })`.
  - Get assistantMsg = response.choices[0].message. Push to messages array.
  - If no tool_calls: return assistantMsg.content (the final reply).
  - For each tool_call: execute via executeToolCall, push tool result message.
  - Track newMessages (all messages added during this turn) for persistence.
  - If MAX_ITERATIONS hit: log warning, return Portuguese fallback "Desculpe, tive um problema tecnico. Um vendedor vai entrar em contato em breve."
  - After the loop, call appendMessages(ctx.conversationId, newMessages) to persist all new messages (user + assistant + tool calls + tool results).
  - Log token usage: response.usage.total_tokens per turn.

```
async (job: Job) => {
  const { instance, phoneNumber, message } = job.data as MessageJobData;

  // Log incoming
  console.log(JSON.stringify({ level: 'info', msg: 'Processing message', jobId: job.id, phone: phoneNumber, preview: message.substring(0, 50) }));

  // 1. Cancel any pending follow-up (lead replied)
  // Import getFollowupQueue from queues.ts — if followup queue exists, remove job
  try {
    const followupQueue = getFollowupQueue();
    await followupQueue.remove(`followup-${phoneNumber}`);
  } catch { /* followup queue may not exist yet — Plan 03 adds it */ }

  // 2. Load or create conversation
  const conversation = await loadOrCreateConversation(phoneNumber);

  // 3. Run agentic loop
  const reply = await runAgentTurn({
    instance,
    phoneNumber,
    userMessage: message,
    conversationId: conversation.id,
    history: conversation.recentMessages,
    lead: conversation.lead,
  });

  // 4. Send reply to lead
  if (reply && reply.trim()) {
    await evolutionClient.sendText(instance, phoneNumber, reply);
  }

  // 5. Schedule follow-up (Plan 03 will implement the queue/worker)
  // Placeholder: try to add delayed job, catch if queue not ready
  try {
    const followupQueue = getFollowupQueue();
    await followupQueue.add('followup',
      { leadId: conversation.lead?.id, instance, phoneNumber, followupNumber: 1 },
      { delay: 24 * 60 * 60 * 1000, jobId: `followup-${phoneNumber}` }
    );
  } catch { /* follow-up queue not available yet */ }

  console.log(JSON.stringify({ level: 'info', msg: 'Agent reply sent', jobId: job.id, phone: phoneNumber }));
}
```
