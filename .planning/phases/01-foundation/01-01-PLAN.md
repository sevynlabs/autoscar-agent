Create the complete Docker infrastructure:

1. **docker-compose.yml** — 6 services exactly as documented in research:
   - `postgres` (postgres:16): POSTGRES_DB=autoscar, POSTGRES_USER=autoscar, POSTGRES_PASSWORD from env, volume postgres_data
   - `redis` (redis:7-alpine): appendonly yes, volume redis_data
   - `minio` (minio/minio:latest): server /data --console-address ":9001", MINIO_ROOT_USER/PASSWORD from env, volume minio_data
   - `evolution-api` (atendai/evolution-api:v2.1.1): CRITICAL — set DATABASE_ENABLED=true, DATABASE_PROVIDER=postgresql, DATABASE_CONNECTION_URI pointing to postgres, all DATABASE_SAVE_* flags true, REDIS_ENABLED=true, REDIS_URI=redis://redis:6379, WEBHOOK_GLOBAL_ENABLED=false. Volume evolution_instances:/evolution/instances. Depends on postgres + redis.
   - `app` (build: .): env_file .env, depends on postgres + redis + evolution-api
   - `nginx` (nginx:alpine): ports 80:80, 443:443, mount ./nginx/nginx.conf, depends on app + evolution-api
   - Network: autoscar-net (bridge)
   - Named volumes: postgres_data, redis_data, minio_data, evolution_instances, certbot_data

2. **Dockerfile** — Multi-stage build:
   - Base: `mcr.microsoft.com/playwright:v1.51-jammy` (includes Chromium deps)
   - Install Node.js 22 if not in base, or use `FROM node:22-bookworm` then `RUN npx playwright install-deps chromium && npx playwright install chromium`
   - WORKDIR /app, COPY package*.json, RUN npm ci, COPY . ., RUN npx prisma generate, RUN npm run build
   - CMD ["node", "dist/main.js"]

3. **nginx/nginx.conf** — Reverse proxy:
   - Upstream `app` on port 3000
   - Upstream `evolution-api` on port 8080
   - Location / → proxy to app
   - Location /evolution/ → proxy to evolution-api (strip prefix)
   - WebSocket upgrade headers for both
   - Health check endpoint at /health

4. **.env.example** — Template with ALL required vars (copy from research code examples section). Include DATABASE_URL for Prisma: postgresql://autoscar:${POSTGRES_PASSWORD}@postgres:5432/autoscar

5. **.dockerignore** — node_modules, dist, .env, .git, .planning

6. **.gitignore** — node_modules, dist, .env, *.log, .DS_Store

   ```
   npm install fastify @fastify/env @fastify/rate-limit bullmq ioredis @prisma/client zod pino dotenv axios
   npm install playwright cheerio
   npm install -D typescript @types/node tsx prisma
   ```

3. **tsconfig.json** — Target ES2022, module NodeNext, moduleResolution NodeNext, outDir dist, rootDir src, strict true, esModuleInterop true, skipLibCheck true, resolveJsonModule true.

4. **src/config/env.ts** — Export a typed env config interface:
   ```typescript
   export interface EnvConfig {
     APP_PORT: number;
     NODE_ENV: string;
     DATABASE_URL: string;
     REDIS_URL: string;
     EVOLUTION_API_URL: string;
     EVOLUTION_API_KEY: string;
     OPENAI_API_KEY: string;
     MINIO_ENDPOINT: string;
     MINIO_USER: string;
     MINIO_PASSWORD: string;
   }
   ```

5. **src/api/plugins/env.ts** — Fastify plugin using @fastify/env with JSON Schema matching EnvConfig. Validate at startup, fail fast with clear error if any required var is missing. Decorate fastify with `config` of type EnvConfig.

6. **src/api/server.ts** — Export `buildServer()` async function:
   - Create Fastify instance with pino logger
   - Register env plugin
   - Register rate-limit plugin (max 100/min global)
   - Add GET /health route returning { status: 'ok' }
   - Return fastify instance (do NOT listen — main.ts handles that)

7. **src/main.ts** — Entry point:
   - Import dotenv/config (for local dev)
   - Import buildServer
   - Call buildServer(), then listen on APP_PORT (default 3000), host '0.0.0.0'
   - Graceful shutdown on SIGTERM/SIGINT

8. **src/db/prisma.ts** — Singleton PrismaClient export:
   ```typescript
   import { PrismaClient } from '@prisma/client';
   const prisma = new PrismaClient();
   export default prisma;
   ```

   - model Vehicle { id String @id @default(cuid()), portalUrl String @unique, model String, year String, price String, mileage String, photos String[], cachedAt DateTime @default(now()), tenantId String? }
