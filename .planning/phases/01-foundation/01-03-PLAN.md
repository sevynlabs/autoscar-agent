1. **src/scraper/autoscar.scraper.ts** — Playwright + Cheerio extraction:
   - `scrapeVehicle(url: string): Promise<Vehicle>` function
   - Launch chromium headless, create context with realistic user-agent (Chrome 121 on Windows)
   - Add init script to hide webdriver flag: `Object.defineProperty(navigator, 'webdriver', { get: () => undefined })`
   - Navigate to url with waitUntil: 'networkidle', timeout: 30_000
   - Wait for page content to load: `page.waitForSelector('h1, [class*="title"], [class*="vehicle"]', { timeout: 15_000 })`
   - Get page HTML with `page.content()`
   - Load HTML into Cheerio
   - Extract vehicle data using MULTIPLE FALLBACK SELECTORS per field (the exact selectors are unknown — this is the highest-risk task):
     - model: Try h1, then [class*="title"], then meta og:title
     - year: Try elements containing /\d{4}/, text matching year patterns
     - km: Try elements containing "km" or "KM", text matching /[\d.]+\s*km/i
     - price: Try elements containing "R$", text matching /R\$\s*[\d.,]+/
     - photos: Try img[src*="autoscar"], gallery images, og:image meta tags
   - IMPORTANT: Log a warning for each field that falls back to a non-primary selector
   - IMPORTANT: Wrap in try/finally to ALWAYS close browser (prevent zombie Chrome processes)
   - Validate extracted raw data with vehicleSchema.parse() — this throws ZodError if required fields missing (SCRP-03)
   - Return validated Vehicle object

2. **src/scraper/scraper.service.ts** — Orchestrator:
   - `getVehicleData(url: string): Promise<{ data: Vehicle; cached: boolean }>` function
   - Validate URL starts with 'https://autoscar.com.br' or 'https://www.autoscar.com.br' — throw clear error otherwise
   - Step 1: Check Redis cache via getCachedVehicle(url)
   - If cached: return { data: cachedData, cached: true }
   - If not cached: call scrapeVehicle(url)
   - On success: cacheVehicle(url, data), return { data, cached: false }
   - On ZodError: Log the specific validation errors (which fields failed), throw a ScraperValidationError with the field details (SCRP-03 — "surfaces a clear validation error")
   - On Playwright timeout/navigation error: Log the URL and error, throw a ScraperNavigationError
   - Export `getVehicleData` and both custom error classes

3. **src/api/routes/scraper.ts** — Test endpoint (Fastify plugin):
   - GET /scraper/vehicle?url={autoscar_url}
   - Call getVehicleData(url)
   - Return 200 with { data, cached }
   - On ScraperValidationError: return 422 with { error: message, fields: failedFields }
   - On ScraperNavigationError: return 502 with { error: message }
   - On invalid URL: return 400 with { error: 'URL must be from autoscar.com.br' }

4. **Update src/api/server.ts** — Register scraper route plugin.
