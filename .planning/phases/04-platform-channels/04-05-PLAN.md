  <files>prisma/schema.prisma, src/webhooks/webhook.service.ts, src/api/routes/webhooks.ts, src/api/server.ts</files>
  <action>
1. Add to prisma/schema.prisma:
   - `model Webhook { id cuid, url String, events String[] (array of event names like "lead.created", "lead.qualified", "lead.stage_changed"), secret String (for HMAC signature verification), active Boolean @default(true), tenantId String?, createdAt, updatedAt }`
   - `model ApiKey { id cuid, name String, key String @unique, userId String, user User @relation, active Boolean @default(true), tenantId String?, createdAt }` — for external API authentication

2. Run `npx prisma db push`.

3. Create src/webhooks/webhook.service.ts:
   - `fireWebhook(eventName: string, payload: Record<string, unknown>)` — async, fire-and-forget:
     a. Query all active Webhooks where events array contains eventName
     b. For each matching webhook: POST to webhook.url with JSON body { event: eventName, timestamp: ISO, data: payload }
     c. Sign the body with HMAC SHA256 using webhook.secret, send as X-Webhook-Signature header
     d. Use axios with 5s timeout, catch errors and log (never throw — webhook failures must not break the main flow)
     e. Run all POSTs in Promise.allSettled (parallel, non-blocking)

4. Create src/api/routes/webhooks.ts (require admin role):
   - GET /webhooks — list all webhooks
   - POST /webhooks — create webhook { url, events[], secret? (auto-generate if not provided using crypto.randomUUID()) }
   - PATCH /webhooks/:id — update webhook (url, events, active)
   - DELETE /webhooks/:id — hard delete webhook

5. Register webhooks routes in server.ts.
