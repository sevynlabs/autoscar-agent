1. Create src/channels/channel.interface.ts:
   ```typescript
   export type ChannelType = 'whatsapp' | 'instagram' | 'sms';

   export interface IChannel {
     type: ChannelType;
     sendText(to: string, text: string, context?: Record<string, string>): Promise<void>;
     sendMedia(to: string, mediaUrl: string, caption?: string, context?: Record<string, string>): Promise<void>;
   }
   ```
   The `context` param carries channel-specific data (e.g., WhatsApp instance name, Instagram page token).

2. Create src/channels/whatsapp.channel.ts:
   - Implements IChannel with type='whatsapp'
   - sendText delegates to evolutionClient.sendText — context.instance is the Evolution API instance name
   - sendMedia delegates to evolutionClient.sendMedia
   - Wraps existing evolution.client.ts — no new external dependencies

3. Create src/channels/instagram.channel.ts:
   - Implements IChannel with type='instagram'
   - Uses axios to call Instagram Graph API (graph.facebook.com/v21.0)
   - sendText: POST /{page-id}/messages with { recipient: { id: recipientId }, message: { text } }, using page access token from context.pageAccessToken or env INSTAGRAM_PAGE_TOKEN
   - sendMedia: POST /{page-id}/messages with { recipient: { id: recipientId }, message: { attachment: { type: "image", payload: { url: mediaUrl } } } }
   - Read INSTAGRAM_PAGE_TOKEN and INSTAGRAM_PAGE_ID from process.env (lazy, with graceful skip if not configured)

4. Create src/channels/channel.manager.ts:
   - Factory function: `getChannel(type: ChannelType): IChannel`
   - Returns cached singleton per type
   - Throws clear error if channel type not supported
   - Export `channelManager = { getChannel }`
