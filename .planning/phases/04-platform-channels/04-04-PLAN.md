<task type="auto">
  <name>Task 1: Dashboard analytics API routes</name>
  <files>src/api/routes/dashboard.ts, src/api/server.ts</files>
  <action>
1. Create src/api/routes/dashboard.ts with these endpoints (all require auth):

   GET /dashboard/stats?from=ISO&to=ISO — returns:
   ```json
   {
     "totalLeads": 42,
     "newLeadsToday": 5,
     "conversionRate": 0.38,
     "avgResponseTimeMs": 4500,
     "leadsByStage": [{ "stage": "Novo", "count": 15 }, ...],
     "leadsByDay": [{ "date": "2026-03-18", "count": 8 }, ...],
     "leadsByChannel": [{ "channel": "whatsapp", "count": 35 }, ...]
   }
   ```
   - totalLeads: count of leads in date range (createdAt between from/to)
   - newLeadsToday: count of leads created today
   - conversionRate: leads that reached a stage with name containing "qualificad" / total leads
   - avgResponseTimeMs: average time between a lead message (role='lead') and the next agent message (role='assistant') — use Prisma raw query for this calculation
   - leadsByStage: group by on lead.stageId, join stage name
   - leadsByDay: group by date(createdAt), count per day
   - leadsByChannel: group by conversation.channel, count

   GET /dashboard/agent-performance?from=ISO&to=ISO — returns:
   ```json
   {
     "totalConversations": 30,
     "messagesPerConversation": 8.5,
     "qualifiedRate": 0.4,
     "handoffRate": 0.15,
     "avgMessagesToQualify": 6
   }
   ```
   - totalConversations: count of conversations in range
   - messagesPerConversation: avg messages per conversation
   - qualifiedRate: conversations where lead reached qualified stage / total
   - handoffRate: leads with humanOverride=true / total
   - avgMessagesToQualify: average message count for qualified leads

2. Use Zod to validate query params (from/to as ISO date strings, both optional — default to last 30 days).

3. Register dashboard routes in server.ts.
