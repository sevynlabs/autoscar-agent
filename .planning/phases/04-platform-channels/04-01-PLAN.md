<task type="auto">
  <name>Task 1: User/Session Prisma models + Fastify auth plugin + auth/user routes</name>
  <files>prisma/schema.prisma, src/api/plugins/auth.ts, src/api/routes/auth.ts, src/api/routes/users.ts, src/api/server.ts, src/config/env.ts, prisma/seed.ts</files>
  <action>
1. Add to prisma/schema.prisma:
   - `model User { id cuid, email String @unique, name String, passwordHash String, role String @default("operator"), tenantId String?, active Boolean @default(true), createdAt, updatedAt }` — role is "admin" or "operator"
   - `model Session { id cuid, userId String, user User @relation, token String @unique, expiresAt DateTime, createdAt }` with cascade delete on user
   - Add `User` relation fields to Lead (assignedTo -> userId) and LeadNote (createdBy -> userId) — both optional/nullable for backward compat

2. Add JWT_SECRET to EnvConfig in src/config/env.ts and to the env plugin schema. Use jose library (NOT jsonwebtoken — CommonJS issues with Edge runtime and Fastify ESM).

3. Install dependencies: `npm install jose bcrypt @types/bcrypt` in the backend root.

4. Create src/api/plugins/auth.ts as a fastify-plugin:
   - Decorate fastify with `authenticate` preHandler hook
   - Hook reads `Authorization: Bearer <token>` header
   - Verifies JWT with jose jwtVerify using JWT_SECRET
   - Looks up Session in DB (token must exist, not expired)
   - Attaches `request.user = { id, email, name, role }` to request
   - Returns 401 if invalid/expired
   - Export a `requireRole(role: string)` preHandler factory for admin-only routes
   - SKIP auth for: POST /auth/login, GET /health, POST /webhook (Evolution API callbacks need no auth)

5. Create src/api/routes/auth.ts:
   - POST /auth/login — accepts {email, password}, validates with bcrypt.compare against User.passwordHash, creates Session with JWT (24h expiry), returns { token, user: { id, email, name, role } }
   - POST /auth/logout — requires auth, deletes Session by token, returns 204
   - GET /auth/me — requires auth, returns current user from request.user

6. Create src/api/routes/users.ts (all require admin role):
   - GET /users — list all users (id, email, name, role, active, createdAt)
   - POST /users — create user (email, name, password, role), hash password with bcrypt (salt rounds 12), return user without passwordHash
   - PATCH /users/:id — update user (name, role, active), admin cannot deactivate self
   - DELETE /users/:id — soft-delete (set active=false), admin cannot delete self

7. Register auth plugin AFTER cors/rateLimit but BEFORE routes in server.ts. Register auth and users routes.

8. Update prisma/seed.ts to create a default admin user: email admin@autoscar.com, password "admin123" (bcrypt hashed), role "admin". Log the credentials on seed completion.

9. Run `npx prisma db push` and `npx prisma db seed`.
