<!-- API endpoints from Plan 01 that this plan consumes -->

GET /leads?pipelineId=&stageId=&search= → Lead[] (with stage, latest note)
GET /leads/:id/detail → Lead with stage, notes[], conversation.messages[]
PATCH /leads/:id → { name?, city?, creditStatus?, paymentMethod?, vehicleUrl? } → Lead

GET /pipelines → Pipeline[] with stages[]

<!-- Lead shape from Prisma schema -->
```typescript
interface Lead {
  id: string;
  phone: string;
  name: string | null;
  city: string | null;
  creditStatus: string | null;
  paymentMethod: string | null;
  vehicleUrl: string | null;
  stageId: string | null;
  pipelineId: string | null;
  humanOverride: boolean;
  createdAt: string;
  updatedAt: string;
  stage: { id: string; name: string; order: number } | null;
  notes?: { id: string; content: string; type: string; createdAt: string }[];
  conversation?: { messages: { id: string; role: string; content: string; createdAt: string }[] };
}

interface Pipeline {
  id: string;
  name: string;
  stages: { id: string; name: string; order: number }[];
}
```

   - Fetch pipelines with TanStack Query: useQuery(['pipelines'], () => api.get('/pipelines'))
   - Fetch leads with TanStack Query: useQuery(['leads', { pipelineId, search }], () => api.get('/leads?...'))
   - Search input (shadcn/ui Input) with 300ms debounce (useState + useEffect with setTimeout)

2. Create frontend/src/components/kanban/KanbanBoard.tsx ('use client'):
   - DndContext with closestCorners collision detection
   - PointerSensor with activationConstraint { distance: 8 } to prevent accidental drags
   - Maintain local state for optimistic column moves
   - onDragStart: set activeId
   - onDragOver: find target column from `over.id`, update local leads state optimistically (move lead to new column)
   - onDragEnd: call api.patch(`/leads/${activeId}/move`, { stageId: targetColumn.id }) — on error, rollback local state
   - DragOverlay at root level rendering LeadCard with isDragging=true
   - Layout: flex row with gap-4, overflow-x-auto, min-h-[calc(100vh-120px)]
   - Map over columns, render KanbanColumn for each

3. Create frontend/src/components/kanban/KanbanColumn.tsx ('use client'):
   - Accept column (stage) and leads for that column as props
   - Use useDroppable({ id: column.id }) for empty column drop target (CRITICAL: without this, empty columns reject drops)
   - Wrap lead cards in SortableContext with verticalListSortingStrategy
   - Items array = leads in this column mapped to ids
   - Render column header with stage name + lead count badge
   - Min-width: 280px, bg-muted/50 rounded-lg p-3
   - Map over leads, render LeadCard for each

4. Create frontend/src/components/kanban/LeadCard.tsx ('use client'):
   - Accept lead and optional isDragging prop, plus onClick callback
   - useSortable({ id: lead.id })
   - Apply CSS.Transform.toString(transform) + transition to style
   - Show: lead.name or lead.phone, stage badge, latest note preview (truncated), createdAt relative time
   - onClick opens LeadDetail (callback from parent)
   - Card uses shadcn/ui Card component with cursor-grab, hover:shadow-md transition
   - When isDragging, opacity 0.5
