   ```
   npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --yes
   ```

2. Install Phase 3 dependencies in frontend/:
   ```
   cd frontend
   npx shadcn@latest init --defaults
   npx shadcn@latest add card badge button sheet dialog input label table tabs scroll-area separator select textarea
   npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
   npm install socket.io-client
   npm install @tanstack/react-query
   npm install react-hook-form @hookform/resolvers zod
   ```

3. Create frontend/src/lib/api.ts:
   - Export `api` object with methods: get(path), post(path, body), patch(path, body), delete(path)
   - Base URL: `/api/backend` (proxied via Next.js rewrites)
   - All methods call fetch with JSON headers, throw on non-ok response
   - Type-safe generic: `api.get<Lead[]>('/leads')` returns typed data

4. Create frontend/src/lib/socket.ts:
   - Mark with `'use client'` at top (CRITICAL for Next.js App Router SSR safety)
   - Export `getSocket()` function returning singleton Socket instance
   - Connect to `process.env.NEXT_PUBLIC_SOCKET_URL ?? 'http://localhost:3001'`
   - Set `autoConnect: false` — components call `sock.connect()` in useEffect

5. Create frontend/src/providers/QueryProvider.tsx:
   - Mark with `'use client'`
   - Export QueryProvider component wrapping children with QueryClientProvider
   - Create QueryClient with defaultOptions: queries staleTime 30s, retry 1

6. Update frontend/src/app/layout.tsx:
   - Wrap children with QueryProvider
   - Set metadata title to "Autoscar CRM"
   - Use Inter font from next/font/google

7. Update frontend/src/app/page.tsx:
   - Redirect to /crm using next/navigation redirect()

8. Create frontend/next.config.ts:
   - Add rewrites: source '/api/backend/:path*' destination `${process.env.BACKEND_URL ?? 'http://localhost:3001'}/:path*`
   - This proxies REST calls to Fastify, avoiding CORS for REST (Socket.IO still needs CORS on backend)

     ```yaml
         - app
       networks:
         - autoscar-net
     ```
