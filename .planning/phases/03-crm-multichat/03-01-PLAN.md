1. Create src/api/routes/leads.ts with prefix '/leads':
   - GET /leads?pipelineId=&stageId=&search= — Zod-validated query params, Prisma findMany with optional WHERE filters (search uses OR on name contains insensitive + phone contains), include stage + latest note (take 1 desc). Return array.
   - GET /leads/:id/detail — findUniqueOrThrow with include: stage, notes (asc), conversation with messages (asc). CRM-05.
   - PATCH /leads/:id — Accept body { name?, city?, creditStatus?, paymentMethod?, vehicleUrl? }, call updateLead from lead.service.ts, emit fastify.io.emit('lead:updated', updated). CRM-06.
   - PATCH /leads/:id/move — Accept { stageId }, call moveToStage, emit fastify.io.emit('lead:moved', { leadId, stageId }). CRM-01 backend.
   - PATCH /leads/:id/handoff — Accept { override: boolean }, prisma.lead.update humanOverride, emit fastify.io.emit('lead:handoff', { leadId, humanOverride }). WAPP-06.
   - POST /leads/:id/notes — Accept { content }, call addNote with type 'human', emit fastify.io.emit('lead:note-added', note).

2. Create src/api/routes/pipelines.ts with prefix '/pipelines':
   - GET /pipelines — findMany include stages (orderBy order asc) + _count of leads per stage
   - GET /pipelines/:id — findUniqueOrThrow include stages orderBy order
   - POST /pipelines/:id/stages — Accept { name }, create stage with order = max(existing orders) + 1
   - PATCH /pipelines/:pipelineId/stages/:stageId — Accept { name?, order? }, update stage. If order changed, reorder other stages.
   - DELETE /pipelines/:pipelineId/stages/:stageId — Delete stage. Reassign leads in that stage to null stageId.
   - GET /pipelines/:id/rules — call listRules from qualification-rule.service.ts
   - POST /pipelines/:id/rules — call createRule, accept { field, operator, value, stageTrigger }
   - DELETE /pipelines/:pipelineId/rules/:ruleId — call deleteRule

3. Create src/api/routes/conversations.ts with prefix '/conversations':
   - GET /conversations?limit=50 — findMany include lead (name, phone, stage), messages (take last 1 for preview), orderBy updatedAt desc. WAPP-05.
   - GET /conversations/:id/messages — findMany messages for conversation, orderBy createdAt asc
   - POST /conversations/:id/message — Accept { content, instance }, creates Message with role='human', calls evolutionClient.sendText to send the message to lead's phone, emit fastify.io.emit('message:new', message). This is the operator reply endpoint.
